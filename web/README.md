# web — фронтенд SCADA

Vue 3 + TypeScript + Vite, Pinia, Vue Router, Leaflet (`CRS.Simple`: план в метрах), ECharts.

```bash
npm install
npm run dev        # http://127.0.0.1:5173, проксирует /api -> :8000, /sim -> :8010, /conn -> :8001 (бэкенд: python dev.py up)
npm run build      # проверка типов + сборка в dist/
npm test           # vitest
npm run api-types  # перегенерировать src/api/schema.d.ts из ../contracts/openapi.json
```

В Docker (`python dev.py up`) фронт собирается в nginx-образ: http://localhost:8080. nginx проксирует те же пути, что и Vite, поэтому приложение всегда ходит на свой origin.

## Экраны

| Путь | Что | Право |
|---|---|---|
| `/` | Карта: здания, помещения по этажам, дороги, геозоны, датчики по статусам, техника в движении, люди по зданиям, пульсация объектов с тревогами; лента тревог; карточка объекта (значения, история с порогами, маршрут машины); «Сценарии» — чит-меню симулятора | `map:view` |
| `/alerts` | Журнал тревог: фильтры, подтверждение/закрытие с комментарием | `map:view` |
| `/kpi` | Пробег и загрузка техники, КПП, проходы по СКУД, тревоги и время реакции | `kpi:view` |
| `/analytics` | Replay треков с таймлайном и тревогами; тепловая карта | `kpi:view` |
| `/registry` | Датчики (пороги с версиями, добавление, загрузка CSV с проверкой) и пропуска/номера | `sensors:view` (+ `sensors:edit`) |
| `/connectors` | «Подключить датчик за 5 минут»: каталог форматов, поля по JSON Schema, выпуск/отзыв ключей, тестовая отправка через сервис коннекторов с подтверждением из live-состояния, команды curl / MQTT / Python, последние отказы (DLQ) | `sensors:view` (+ `connectors:manage`) |

## Устройство

- `src/api/client.ts` — `openapi-fetch` с типами из контракта; токен в каждый запрос, на 401 один общий refresh и повтор.
- `src/stores/live.ts` — снимок `/state/live` + поток `WS /ws/live` (`src/lib/ws.ts`: переподключение с backoff, на 4401 — refresh). Обновления копятся и применяются раз в кадр.
- `src/components/PlanMap.vue` — статика плана; слои (`LiveLayer`, `ReplayLayer`, `HeatLayer`, `RouteLayer`) получают карту через `provide/inject`. Машины двигаются плавно CSS-переходом между фиксами ГЛОНАСС.
- Цвета графиков проверены валидатором палитр для тёмной поверхности; статусные цвета (норма/вне нормы/критично) не используются для серий и всегда подписаны.
