# Техническое задание (хакатон, задание 3)

Разработка информационной системы для мониторинга и контроля логистической инфраструктуры производственного предприятия, включающего множество складских, офисных и производственных зданий.

Информация поступает с датчиков: транспортных средств, датчиков доступа в помещения, иных датчиков на усмотрение разработчика. Желательна визуализация на карте предприятия.

## Уровни системы

1. **Уровень представления** — интерактивный интерфейс: перемещения людей, техники и состояния объектов в реальном времени.
2. **Уровень данных** — сбор информации с датчиков, расчёт значений нормы, алерты при отклонениях.
3. **Уровень коннекторов** — показываем, что можем интегрировать любые существующие на рынке датчики по API.

## На подумать

- Возможность «размечать предприятие»: создавать на карте помещения, внутри — интерактивные схемы установки датчиков (редактор в стиле «Sims»).

## Контекст с доски (`board.png`)

- **Фронтенд:** карта; создание/редактирование планировки; отслеживание маршрутов; схема помещений и дорог; статичные объекты и объекты в движении; список датчиков; установка номинальных значений; агрегированные данные; ВК-бот с алертами.
- **Тестовые данные:** машины катаются, турникеты на проходной; алерты: машина сломалась, пропуск вне базы, время нерабочее. Сценарии запускаются из «чит-меню» на демо.
- **Бэкенд:** готовая витрина данных (API, JSON). Из ClickHouse собираем данные в витрину, чтобы не грузить систему.
- **БД 1 — Postgres:** витрины данных, логины/хэши паролей для авторизации, спецификации датчиков.
- **БД 2 — ClickHouse:** вся телеметрия всех датчиков, связь по id датчика (открылось что-то, температура, давление, скорость, уровень топлива).
- **Датчик:** название, описание, метрики, критерии метрик (минимум, норма, максимум, критическое). Все датчики делаем API-совместимыми (охватываем готовый рынок).
- **Модуль входного API:** универсальный под датчики; интеграция с 1С-ЭПД (отображение подписания ЭТрН, ЭПЛ, ЭЭЗ); интеграция с 1С.
- **Модуль предиктивной аналитики:** состояние износа.
- **Виды датчиков:** камера (по номерам), датчик входа (по пропуску), автомобильный (ГЛОНАСС, данные машины), датчик движения (охранная система), температура и влажность (складские помещения).
- Дать возможность загрузить список датчиков (bulk).
